## Before launch

- **Trademark check.** Several hotels named "Pardis" operate in Iran (for example in Karaj, Tehran and Rasht). "Bagh-e Pardis" did not match an existing hotel in a web search, but that is not a trademark clearance. Get one before printing QR codes or signage.
